# Public image assets

Store approved, production-ready visual assets in this directory.

## Recommended folders

- `branding/` — approved KERNEL and institutional logos.
- `events/` — event banners, posters and event-specific artwork.
- `speakers/` — approved speaker portraits.
- `sponsors/` — sponsor logos supplied or approved by the organisers.
- `committee/` — approved core committee portraits.
- `gallery/` — approved event photographs.

## Asset guidelines

- Use only assets approved by the organising team.
- Prefer WebP or optimized AVIF for photographs.
- Use SVG for suitable logos and vector artwork.
- Use descriptive, lowercase filenames with hyphens.
- Optimize images before committing them.
- Do not commit fake event artwork, random stock images or temporary placeholder images.
- Confirm image usage rights and permissions before publication.

The folders above are recommendations. Create them when approved assets become available.
