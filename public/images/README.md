# Image assets

| Folder | Use | Notes |
|---|---|---|
| `hero/` | Homepage hero background | `kernel-hero.jpg` is the official poster artwork. Replace the file (same name) or change `heroImage` in `data/site.json`. |
| `speakers/` | Speaker portraits | Square or 4:5, at least 800px wide. Reference from `data/speakers.json`. |
| `sponsors/` | Sponsor logos | SVG or transparent PNG. Reference from `data/sponsors.json`. |
| `core-committee/` | Committee portraits | Square, at least 600px. |
| `gallery/` | Curated club-event photographs | Optimized WebP frames referenced by `data/gallery.json`. Keep the full Drive archives linked from `data/gallery-clubs.ts`. |
| `brand/` | Logos | Place approved logo files here. |

`placeholder.svg` is a neutral stand-in used by sample records. Do not commit placeholder images pretending to be final event artwork.
