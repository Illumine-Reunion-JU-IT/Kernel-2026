# Aftermovie / teaser video

Drop your video here as **`kernel-aftermovie.mp4`** (H.264, 1920x1080, under ~15 MB works best; muted autoplay loop).
The homepage video section picks it up automatically. To use a different file or an https URL, change `videoUrl` in `data/site.json`.
Set `videoUrl` to `null` to show the "coming soon" state.
